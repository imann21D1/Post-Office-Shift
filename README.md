# 📮 Post Office Shift

> Can you handle the shift?

A Roblox work simulation game where you take the role
of a postal worker and handle a real-time shift at a post office.

## 🎮 Concept

The player works at a fixed postal workstation.

During each shift, players:
- serve customers
- process packages
- weigh parcels
- enter information into the computer
- print receipts
- process payments
- handle unexpected situations

The game focuses on realistic but fun workplace interactions.

## 🎯 Core Experience

Customer arrives
↓
Understand the request
↓
Process the package
↓
Use workplace equipment
↓
Complete the transaction
↓
Customer leaves
↓
Next customer
